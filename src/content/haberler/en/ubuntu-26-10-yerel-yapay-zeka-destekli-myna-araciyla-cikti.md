Canonical has officially released Ubuntu 26.10 Stonking Stingray on October 15, featuring the GNOME 51 desktop environment and the Linux 7.3 kernel. Designed for users looking to follow the latest software features following previous releases, this new version also includes an early preview of a local speech recognition tool, which is described as the initial step in the platform's artificial intelligence roadmap.

Named Myna, the new tool converts spoken words into text directly on the user's computer without relying on external cloud services. While broader intent-driven desktop use cases are outlined among future objectives, installing this new operating system release does not imply that computers will instantly manage all applications entirely through voice commands.

Regarding hardware compatibility, the Linux 7.3 kernel introduces comprehensive support for Intel Xe3P, AMD Zen 6, and new Nvidia graphics drivers. Additionally, Canonical provides an amd64v3 installation option tailored for modern x86 computers alongside desktop system images for RISC-V architectures. On the security front, the transition to Rust-based coreutils has been completed, and Sequoia PGP is utilized to verify APT repository signatures.

Provided strictly as an early technology preview, Myna is not enabled by default in standard installations. Users can interact with the feature by holding down a designated keyboard key to dictate text directly into their currently active application. Audio processing occurs locally on the local machine without transmitting voice recordings to any external network infrastructure.

Ubuntu 26.10 is scheduled to receive nine months of ongoing software support through July 2027. In comparison to long-term support releases, systems running Ubuntu 26.04 LTS with TPM-backed full disk encryption cannot perform a direct in-place upgrade immediately at launch, though developers intend to enable this migration path later.
