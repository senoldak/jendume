Anthropic has launched a new billing system, dubbed "Linked Billing," in beta, designed to streamline how developers manage costs for applications built on the Claude API. This feature allows developers to bill AI usage directly to a customer’s own Claude organization, rather than absorbing all costs themselves. Developers now have the flexibility to choose, on a per-request basis, whether the developer or the customer covers the cost of the API call.

This development marks a significant shift in how AI-powered software is monetized and managed. For companies building enterprise-grade AI solutions, this capability simplifies cost management by allowing them to pass AI expenses directly to the end-user's account. Customers can set monthly spending caps for each specific application within the Claude Console, providing them with greater control over their AI budgets. If a payment cannot be processed, the system refuses the request rather than charging the developer, ensuring financial predictability.

However, the feature comes with specific limitations. It is currently available only to organizations that pay Anthropic directly. Customers billed through major cloud providers like AWS, Google Cloud, or Azure are excluded from this model. Furthermore, credits from existing Claude plans or Anthropic’s startup programs cannot be applied to these linked billing requests.

There is also a crucial caveat regarding data privacy. A customer’s existing data protection agreements, such as zero data retention policies or HIPAA compliance, do not automatically carry over to these requests. Consequently, organizations must carefully evaluate their data governance frameworks when adopting this billing structure. By introducing this system, Anthropic aims to make the economics of AI integration more transparent and manageable. This move signals a maturing AI ecosystem where cost-sharing mechanisms are becoming as sophisticated as the models themselves, paving the way for more scalable and sustainable AI-powered business applications.
