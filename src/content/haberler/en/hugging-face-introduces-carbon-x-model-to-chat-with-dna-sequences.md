Hugging Face has announced the release of Carbon-X, a new artificial intelligence model designed to interact with genetic code using natural language. This model enables researchers to ask questions about DNA sequences and receive detailed analyses directly. According to the company, the system stands out as the most powerful and up-to-date member of the Carbon family, introducing a fresh approach to processing genetic data.

Carbon-X provides an interface where researchers can input a DNA sequence and ask questions in plain language, essentially allowing genetic code to be analyzed like a chatbot. Experts note that this technology allows researchers to examine text-based DNA sequences without needing a physical laboratory device, yielding strong results particularly in predicting mutation effects and completing DNA sequences.

One of the most notable features of the model is its strong privacy advantage. While popular artificial intelligence models like ChatGPT or Claude typically operate on the cloud and require data to be sent to remote servers, Carbon-X can run locally on researchers' own hardware. This allows scientists to analyze unpublished or sensitive data on their own computers without sharing it externally, ensuring academic security.

However, the company also acknowledges certain limitations. Carbon-X can occasionally make erroneous counts or fabricate details if insufficient information is provided, and output quality may drop when very long DNA sequences are requested. Offered as an open model, it allows scientists to examine its working principles and test its capabilities independently.
