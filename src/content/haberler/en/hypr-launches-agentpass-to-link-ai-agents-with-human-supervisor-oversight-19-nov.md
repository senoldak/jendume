HYPR has launched the AgentPass platform to manage and monitor the activities of autonomous AI agents. The system aims to enhance corporate accountability by linking every action performed by an agent to the identity of a verified human supervisor. As AI agents in the workplace evolve from merely answering questions to actively operating software, the need for robust security measures has become paramount. AgentPass addresses this shift by serving as an identity-first control plane that determines not only what an agent can do, but whose authority it is utilizing during its operations.

In traditional setups, agents might possess broad and standing permissions through shared service accounts or developer API keys, which creates significant security vulnerabilities. AgentPass fundamentally alters this access model. Agents begin without any standing access; instead, they operate using short-lived digital tokens scoped to specific tools and tasks. This architecture ensures that an agent's authority is aligned with current job requirements rather than a one-time approval granted during installation. Changes in a supervisor's organizational role are immediately reflected in the agent's permissions, and offboarding processes automatically block subsequent requests.

The platform specifically enhances the security of coding tools such as Claude Code, Codex, and Cursor, enabling sensitive actions to be approved before execution and allowing supervisors to halt activities remotely. Operating on Windows and macOS workstations, the system provides visibility into local workflows that are often not centrally managed. Developers can integrate assistants running on local terminals or repositories into the system, allowing them to audit the permissions these tools operate under. HYPR describes this architecture as a control plane designed to ensure that AI agents are used more securely and controllably in business processes, thereby reducing cybersecurity risks. A critical aspect of this design is that while disabling an agent blocks its next request, it cannot undo an action already taken, underscoring the necessity of proactive human oversight.
