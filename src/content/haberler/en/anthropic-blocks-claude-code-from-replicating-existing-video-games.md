Anthropic has implemented a new restriction for its AI model Claude, preventing it from recreating existing video games. Discovered within the code of Claude Code version 2.1.314, this rule aims to stop the replication of games even if their titles are altered. The company has not yet issued an official statement regarding the full scope of this limitation.

The new guidelines establish a clear framework for Claude in software development. The AI can still assist users in creating original games, generating specific types of projects, and bringing new ideas to life. However, requests to reproduce games that are already available on the market will be denied. It remains unclear whether the restriction applies exclusively to certain models or across the entire platform.

During tests, Claude declined requests to recreate existing games such as Pokemon Diamond, citing the new rules. In contrast, the model adopted a different approach regarding tasks like transforming source codes into readable languages, compiling files, or assisting with platform migration. For instance, transforming code to run games on Windows or Mac has seen different handling.

This subtle distinction matters for developers looking to port games to different platforms. While previous projects involving platform adaptations were feasible, the exact boundaries of how Claude will evaluate similar requests moving forward remain uncertain as Anthropic has yet to clarify the broader rollout of the rule.
