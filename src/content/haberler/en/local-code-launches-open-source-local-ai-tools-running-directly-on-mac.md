The creators of Draw Things have launched Local Code, an open-source application designed to download and run AI models while working directly with files on Mac. The developer announcement brings together tasks such as coding, spreadsheet management, document editing, presentation building, and image generation within a single application. For users aiming to run local artificial intelligence on Mac, the primary distinction is that necessary tools are bundled within the application, ensuring that prompts and files are not sent to cloud providers when a local model is chosen. Systems downloaded through Local Code operate directly on the hardware of the Mac. Python, JavaScript, and shell tools are included in the provided environment, removing the need to install separate tools for tasks like reading a spreadsheet or creating a presentation. However, download sizes and memory requirements vary significantly depending on the selected model. According to developer details, the Qwen 3.8 27B model requires at least 16 GB of memory with 32 GB recommended, while storage usage ranges from approximately 10 to 21 GB. The application can also keep portions of larger models on the SSD and load them as needed. For daily tasks, the software supports reading Word documents, updating spreadsheets, and working on PowerPoint files. Local usage is offered entirely free of charge, while cloud credits start at 9.99 dollars with no subscription requirement.
