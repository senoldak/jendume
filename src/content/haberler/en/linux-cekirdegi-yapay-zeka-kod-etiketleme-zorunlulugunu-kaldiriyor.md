Linux kernel developers are moving to remove the requirement for contributors to disclose when they use AI coding assistants. During the Maintainers Summit, a consensus was reached to deprecate the Assisted-by tag that was introduced earlier to track advanced coding tool usage. Sasha Levin proposed the change on the mailing list after extensive discussions among contributors. Several developers had previously questioned the purpose of the tag, noting that it lacked universal enforcement and effectively acted as free advertising for proprietary language models. Laurent Pinchart argued against removing the tag without another disclosure mechanism, while Linus Torvalds dismissed the requirement, stating that understanding what one is doing matters far more than the specific tools utilized.

Torvalds noted that while AI tools can stress maintainers out, they also actively help discover real security bugs and improve the overall code base. Discussions during the Maintainers Summit heavily revolved around making AI tools less stressful for maintainers, with automated review systems also entering the mailing lists. Different open-source projects continue to adopt contrasting stances, with NetBSD banning generative code entirely and receiving donations exceeding its target, while the Linux project focuses on code improvement. The Linux project will officially drop the mandatory documentation requirement moving forward.
