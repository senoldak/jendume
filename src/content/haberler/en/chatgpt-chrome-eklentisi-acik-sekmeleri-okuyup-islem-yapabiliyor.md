OpenAI has rolled out a major update for its ChatGPT browser extension, introducing direct access to open browser tabs. Users can now have the AI analyze web pages, compare products across different tabs, and streamline daily workflows by utilizing specific tags within the web or desktop application. For instance, individuals comparing multiple items across different pages can analyze product dimensions, prices, delivery times, and return policies instantly.

The updated extension allows users to execute complex and multi-step tasks directly within the browser environment. Users can ask ChatGPT to fill out registration forms using event summaries, schedule dental appointments, or draft emails based on contractor agreements found in open tabs. Before completing these actions, the system aims to reduce error margins by confirming details with the user.

Alongside the tab-reading feature, OpenAI has revamped the sidebar interface. Users can access their chat history, interact with the assistant, and organize or group open tabs without leaving their current web page. The extension is also compatible with Chromium-based browsers such as Microsoft Edge, Brave, and Opera.

With these new capabilities, OpenAI aims to expand the usability of ChatGPT within existing browsers. This move enhances user productivity and strengthens the company's position against competing browser-based artificial intelligence solutions.
