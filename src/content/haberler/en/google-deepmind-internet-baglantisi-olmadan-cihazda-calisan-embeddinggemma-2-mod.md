Google DeepMind has launched EmbeddingGemma 2, an open-weight multimodal model that maps text, code, images, audio, and video into a single shared embedding space directly on consumer hardware. The release follows the original text-focused EmbeddingGemma, which surpassed 20 million downloads among developers building local search and retrieval tools.

Built on the Gemma 4 architecture and released under a commercially permissive Apache 2.0 license, EmbeddingGemma 2 contains 740 million parameters—making it compact enough for efficient on-device inference without cloud connectivity.

## Searching Across Media Without Leaving the Device

Because the model processes multiple modalities natively in one unified space, an application can locate a specific video clip from a spoken voice memo or search through hours of audio recordings using a simple text query.

Processing these embeddings locally keeps sensitive personal files on the user’s own device while enabling fast, offline-capable AI search across everyday applications.
