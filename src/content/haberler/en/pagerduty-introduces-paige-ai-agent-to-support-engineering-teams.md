Operations management software company PagerDuty has introduced Paige, a new artificial intelligence agent designed to operate as a member of site reliability and engineering teams. The agent runs on the company's flagship product, which has been renamed the PD Reliability Platform. The launch addresses a growing challenge in the industry as AI coding tools write more production software with minimal human review. Company executives note that applications built on AI models introduce unique risks such as model drift, token runaway and leaked personal data, requiring automated resilience to keep complex systems running smoothly.

Paige operates based on permissions configured team by team. Teams keeping a person in the loop achieve faster triage while the agent acts autonomously only in well-understood, low-risk scenarios. It provides recommendations accompanied by evidence and confidence levels, and previously resolved incidents are written to a shared memory that the agent consults during future failures. In a benchmark report released with the launch, the company stated that Paige outperformed leading AI coding agents in diagnosing simulated information technology incidents.

The renamed platform provides incident commanders and team managers with a new console that brings together incidents, on-call rotations and AI agents into a single view. Responders can execute incidents end to end within Slack or Microsoft Teams. Canadian telecommunications company Telus integrated the platform into its centralized internal incident tool, noting that PagerDuty's Scribe Agent processes every incident so responders do not need to manually document unfolding events.

PagerDuty also launched PD Labs to test early-stage features directly with design partners. Topology, Deep Investigation and SRE Workbench are available in preview through this initiative, while the core platform is generally available under an operational scale pricing model.
