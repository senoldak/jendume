NVIDIA has released Auto Ontology, an open-source library under the Apache 2.0 license designed to bridge the gap between AI agents and enterprise data warehouses. The new semantic layer framework builds a contextual bridge from enterprise metadata, allowing autonomous agents to write accurate SQL queries based on certified business definitions rather than guessing data structures.

The core problem addressed by the library is data accuracy, as a fast answer from an AI agent is worthless if the underlying data is incorrect. Auto Ontology acts as an intermediary, instructing agents on where data resides, what specific fields mean, and how they should be utilized in business queries. It handles five primary tasks: discovering metadata, grounding metrics, validating queries, exposing context, and learning from certified corrections.

Built on a modern technology stack including Next.js, FastAPI, and PostgreSQL with pgvector, the framework can be deployed locally using Docker Compose or via Kubernetes using Helm charts. While it defaults to NVIDIA's Nemotron models through NIM endpoints, it supports any OpenAI-compatible endpoint. The system exposes nine read-only tools through the Model Context Protocol, ensuring agents query data strictly through the semantic layer rather than browsing raw schemas directly.

According to NVIDIA's self-reported internal testing, the tool cuts ontology creation time by 90 percent. However, the company has not yet published explicit text-to-SQL accuracy scores, providing a separate evaluation harness for developers to run their own benchmarks.

This open framework provides a standardized way for enterprises to integrate AI agents into their data infrastructure. By grounding agent queries in verified business logic, organizations can deploy automated analytics with greater confidence and precision.
