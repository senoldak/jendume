DeepSeek has introduced the updated V4.1-Flash-1017 checkpoint, bringing notable improvements in coding and agent-based tasks. Available now across the company's platform and API ecosystem, the model achieves a score of 77.0 on the DeepSWE benchmark, outperforming several larger competitors while maintaining significantly lower operational costs per task.

The update relies on reinforcement learning with self-feedback, a training method that eliminates the need for human evaluators by allowing the model to use internal confidence scores. This approach enhances end-to-end software development, ranging from game programming to 3D design work. By producing shorter and more efficient outputs, the system achieves a strong balance between high performance and economic feasibility.

Technically, the architecture includes 552 billion backbone parameters and 196 billion Engram parameters, activating 8 billion parameters per token in prefill and 16 billion in decode. It supports a 1 million token context window with up to 384 thousand output tokens, enabling developers to process extensive codebases and large documents seamlessly.

Alongside the language model, DeepSeek has opened its search and fetch APIs to external developers. Powered by an in-house search engine handling hundreds of millions of daily queries, the endpoints are priced at 0.75 dollars per 1,000 successful requests, with temporary free access tiers provided through selected agent harnesses.
