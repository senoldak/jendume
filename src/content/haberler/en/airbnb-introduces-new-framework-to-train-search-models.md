Airbnb has introduced a new framework called CASTLE to train natural language search models. This system aims to solve the "cold-start" problem, which occurs when new listings lack sufficient user traffic to train search algorithms effectively. Guests increasingly prefer searching with natural language, such as "pet-friendly beach house," rather than using rigid filters. However, training these systems requires massive amounts of data. CASTLE uses synthetic data generated by large language models to bridge this gap, allowing search engines to understand user intent even for new properties.

Unlike previous approaches that separated query generation from relevance labeling, CASTLE combines these tasks. This integration significantly reduces errors. In performance evaluations, the system achieved a 9.2-fold reduction in divergence compared to previous methods, showing a much closer alignment with real-user query distributions. Previous methods often struggled with the disconnect between synthetic and real-user data. CASTLE addresses this by using de-identified booking sessions to create contrastive pairs—comparing a booked property with an alternative that was viewed but not chosen.

Human experts validated the system's relevance assignments with an agreement rate between 91% and 93%. This technology enables search engines to focus on user intent rather than just keywords. This development highlights how large language models are evolving beyond simple text generation to become essential tools for optimizing complex search infrastructures, ensuring that users find exactly what they are looking for, even in environments with limited historical data.
