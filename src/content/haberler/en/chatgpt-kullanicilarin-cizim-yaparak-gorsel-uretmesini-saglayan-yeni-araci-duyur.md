OpenAI has rolled out a new feature for ChatGPT designed to transform how users generate images. Integrated with the new Images 2.5 model, the Sketch tool allows individuals to draw rough outlines directly within the platform to set the scene, eliminating the need to craft long and complex text prompts. Available even for free account holders, this feature aims to streamline the creative process and offer unprecedented control over the final output.

The feature can be accessed via the sidebar or mobile menu by selecting Sketch or typing @Sketch in the text field. Users can sketch on touchscreen devices using a finger or stylus, or on computers using a mouse or trackpad. The interface provides various tools including adjustable brush sizes, a color wheel, shapes, arrows, and an eraser to help craft the initial outline.

Once the drawing is finished and submitted with a tick, ChatGPT suggests a prompt based on the sketch, which users can accept or customize before generating the final photograph. Furthermore, the tool includes advanced editing capabilities. Users can select specific areas to add targeted feedback, remove backgrounds, erase unwanted elements, and reframe the aspect ratio into square, portrait, landscape, or widescreen formats.

By bridging the gap between rough human sketches and advanced generative models, this tool significantly enhances user agency in AI art generation. It allows for iterative refinement where tiny adjustments ensure the final image matches the creator's exact vision. As generative AI continues to evolve, intuitive input methods like sketching represent a major step toward more accessible and precise digital creation.
