Apple has started offering a new artificial intelligence tool named Intelligent Assistant in a beta release for Pages, Numbers, and Keynote applications. The integration allows users to handle document writing, spreadsheet organisation, and presentation creation through natural language prompts. Accessing the new capabilities requires specific hardware compatibility and an additional subscription package.

According to the release notes for Numbers version 15.4.1, the assistant aids in interpreting tables, building complex formulas, and visualising numerical data. Users can query the web for current information, generate tables using conversational prompts, and receive automated chart recommendations. Within Pages, the tool focuses on drafting initial texts, expanding sections, adjusting writing tone, and generating accompanying visual shapes.

Keynote receives updates centered around slide creation, animation integration, and presenter note organisation, alongside Interchange Format support for improved file transfers. While standard document viewing and editing remain freely accessible, advanced intelligence features are bundled with the optional subscription plan. The system requires compatible hardware running recent operating system versions to function properly.

The initial rollout is restricted to U.S. English and does not feature regional language support for other markets yet. Users outside the specified language parameters need to consider these limitations before obtaining the update or subscription.
