DeepSeek announced that its open-source AI agent platform, Harness, reached 1.54 million daily active users based on data from November 4. Launched on August 13, the platform has seen rapid adoption. This figure exclusively accounts for users accessing Harness through DeepSeek's official API, meaning those utilizing the platform with different model providers are not included in this count. The user base grew more than fivefold in one month, rising from approximately 271,000 daily active users on September 30.

Harness enables users to autonomously manage file reading, tool invocation, and complex workflows. These capabilities drive significant token consumption. Users consume approximately 92 trillion tokens daily, with an average of 60 million tokens per user. This high consumption rate stems from the agents' ability to operate within continuous processing cycles, distinguishing them from standard conversational chatbots.

The platform's growth is heavily supported by its plugin ecosystem. The number of third-party plugins developed for Harness has reached 35,000. Approximately 60% of active users have created or installed at least one plugin to customize their workflows. DeepSeek plans to further expand this ecosystem by establishing an official plugin store.

The company is also developing a support program to provide plugin developers with token incentives, technical assistance, and increased visibility. The launch date for the plugin store has not yet been officially announced. Through these initiatives, DeepSeek aims to compete directly with AI agent platforms offered by industry leaders such as OpenAI and Anthropic. Harness's flexibility positions it to significantly influence how AI agents are deployed in professional and personal tasks.
