Deploying AI agents at scale for complex, end-to-end tasks remains a persistent challenge for development teams. Despite advanced underlying models, agents frequently struggle inside specific products, prompting teams to write hundreds or thousands of manual evaluation cases. CopilotKit, the company behind open-source agent frameworks with over 38,000 stars on GitHub, has released CLiF in early access to address this exact bottleneck.

Traditional observability tools typically track only the agent's prompts and tool calls while missing the correct path that product users execute daily. The new platform bridges this gap by capturing agent traces and user actions on a single timeline to create full-stack trajectories. Operating through an open interaction protocol, the system safely records what users click, type, and trigger alongside the agent's actions, merging both halves into one unified learning stream.

The platform operates through a four-stage loop consisting of capture, pattern finding, review, and delivery. Sessions are categorized into specific learning containers, where automated analysis surfaces recurring friction points and user workarounds. Crucially, every proposed skill requires human review and approval before publication, ensuring safety and stability. Published skills can then be delivered to the agent without requiring a full redeployment.

By transforming real-world user habits into production evaluations, fine-tuning datasets, and reusable skills, the platform tackles major industry hurdles such as context bloat and evaluation overhead. Fully self-hosted, it represents a significant step toward self-improving agents that adapt seamlessly to actual human workflows.
