OpenAI has introduced two new cybersecurity products under the Daybreak brand, marking its entry into the cybersecurity market. This strategic move transitions the company from being solely a foundational model provider to a developer of specialized security solutions. The newly unveiled tools are designed to identify vulnerabilities in web applications and generate automated patches for identified flaws, aiming to streamline security operations.

The first product, Daybreak Red Team, is currently available through an early access program. This tool utilizes AI agents to conduct continuous and automated scans of web applications. By analyzing the source code and the operational context of an application, these agents map out potential attack paths that a malicious actor might exploit. Beyond discovering new vulnerabilities, the tool also verifies security reports from external researchers or automated scanners, confirming the validity of identified flaws to reduce false positives.

The second product, Daybreak Defense Factory, focuses on automating defensive measures. The system scans a company's codebase to detect security weaknesses and automatically generates patches to address them. Instead of providing a simple list of warnings, the tool creates code proposals that include both the fix and the necessary tests. These proposals are submitted for developer review before being integrated into the main project, ensuring that human oversight remains a critical part of the deployment process.

Both products are powered by OpenAI's GPT-6 Cyber model. By utilizing the same underlying model for both offensive penetration testing and defensive patching, the tools work in tandem to secure digital infrastructure. Led by the Cyber-Applied AI team, this initiative aims to combine the speed of automated scanning with the depth of human penetration testing, offering organizations a new approach to managing their digital security posture.
