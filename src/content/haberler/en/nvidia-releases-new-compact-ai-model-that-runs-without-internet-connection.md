Nvidia has introduced Nemotron 3.5 Bolt E4B, a new model developed for smartphones, small devices, and robotic systems. Designed with a target memory footprint of approximately 4 gigabytes, the new open model can converse in natural language and execute multi-step tasks using application tools without needing an internet connection. Based on Google's Gemma 4 E4B model, the system was enhanced through additional training conducted by the company. The model is engineered to fit within about 4 gigabytes of memory in target use cases, leaving ample space for applications and other models running on the same pipeline. The organization states that compared to its predecessor Nano 4B, the model achieves an average of approximately 40 percent higher quality in basic chat and tool-use tests. Furthermore, evaluations show that the model uses up to 80 percent fewer tokens in reasoning benchmarks compared to other models, reducing computational load, costs, and response times. Nemotron 3.5 Bolt E4B can be deployed across computers, mobile devices, home systems, in-vehicle assistants, gaming characters, robotic systems, and industrial automation applications. Supported hardware platforms include GeForce RTX, Jetson, RTX Spark, and DGX Spark. This local execution approach enables AI features in environments lacking internet connectivity and enhances privacy by reducing the need to send data to external servers. The model also features a 64k token context window and supports 35 languages.
