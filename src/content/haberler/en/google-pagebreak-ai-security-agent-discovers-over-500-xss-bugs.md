Google has published a research paper detailing its autonomous security agent, PageBreak, which has identified over 500 cross-site scripting vulnerabilities across various web applications following its full deployment in January. The system leverages Gemini models to autonomously scan for potential security flaws, but it submits bug reports only after deterministic validators successfully replicate the exploit within an active application environment, achieving a remarkably low false-positive rate.

Operating within an active setting, every security hypothesis undergoes rigorous testing using concrete payloads, such as executing script commands for scripting flaws or triggering outbound network requests. Michał Bentkowski, an information security engineer at Google, emphasizes that the development team made a deliberate choice to focus on deterministic verification from the very beginning. Instead of merely guessing software defects based on surface-level code structures, the platform confirms potential issues against live systems to prevent overwhelming engineering teams with unverified alerts.

At the same time, Google preserves unverified observations internally to improve future scanning mechanisms and refine validation logic, acknowledging that current validators cannot yet detect every complex vulnerability type. Lukas Weichselbaum, a senior staff security engineer at Google, points out that automated security alerts generated by artificial intelligence often appear convincing while ultimately proving incorrect, making independent payload confirmation essential before counting any finding.

Benefiting from the company's integrated code repositories and traffic analysis tools, PageBreak operates with deep visibility into underlying source code. Google plans to connect the agent with other automated remediation projects, such as CodeMender, to streamline the process of drafting and verifying software patches for the security flaws it uncovers.
