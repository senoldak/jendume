Anthropic has released updates for the Model Context Protocol (MCP), which allows AI assistants to interact with software tools and data sources. This protocol acts as a bridge, enabling AI models to communicate with external applications. With the new updates, AI agents can execute extended operations behind the scenes and notify users upon completion, while also asking users for missing information.

At the core of this development is the shift of AI from a chatbot to an active agent. For instance, the new Tasks feature allows a server to run a lengthy job in the background and return updates only when the final outcome is ready. The Elicitation feature enables the AI to pause a process when it encounters missing information and request specific data directly from the user. These capabilities allow AI to manage complex workflows with minimal human intervention.

On the technical side, efficiency improvements are present. A new tool search method that optimizes memory usage for AI models cuts context usage by more than 85 percent across multi-server installations. This means larger and more complex systems can operate with lower hardware costs. Additionally, the upcoming support for file uploads, such as PDFs, spreadsheets, and images, will expand the data processing capacity of the technology.

Introduced as an open standard in November 2024, the protocol has gained industry-wide acceptance. Adopted by other major AI companies, the standard has surpassed 700 million monthly downloads and features over 10,000 connectors. This adoption unifies the fragmented AI ecosystem, allowing different models and tools to communicate using a common language.
