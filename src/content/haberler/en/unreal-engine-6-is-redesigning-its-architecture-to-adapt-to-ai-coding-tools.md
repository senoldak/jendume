After a studio closure left an online game unplayable without server support, a developer used Anthropic’s Claude Code model to rewrite networking features in just a few hours. This demonstrated that agentic AI workflows can effectively bypass elaborate game engine user interfaces. Such developments are now pushing major game engine creators to rethink their long-term strategies.

Epic Games Chief Operating Officer Daniel Vogel noted that software can now be dreamed up extremely fast, pushing the company to pivot heavily toward velocity. Recognizing that large language models struggle to process visual scripting systems effectively, Epic made the decision to remove the Blueprints system in Unreal Engine 6.

In the upcoming version, all code will transition to Verse, a text-based programming language. The engine will also expose its systems through application programming interfaces and store more assets as text, enabling AI tools to interact with and edit game environments directly without relying on graphical menus.

While the traditional editor will evolve rather than disappear, these changes aim to keep the engine relevant as AI coding agents become standard. Developers report that AI also lowers the barrier to switching between different game engines, making cross-engine experimentation significantly easier. Epic Games continues to focus on modularity to ensure interoperability across various ecosystems.
