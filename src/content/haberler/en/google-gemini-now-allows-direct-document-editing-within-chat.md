Google has significantly expanded the file creation and editing capabilities of its Gemini AI model. Users can now view and modify PDFs, Google Docs, Sheets, presentations, Markdown files, TXT files, and code files directly within the chat interface, eliminating the need to switch to external applications. This update shifts the role of AI in the content creation process from a passive generator to an active editing assistant.

With this new functionality, users can open files in full-screen mode, select specific sections, and prompt Gemini to rewrite text, answer questions, or modify content. For instance, users can select a table and ask Gemini to convert it into a chart, or make real-time adjustments to code files. This interactive structure provides significant time savings, particularly for users working on long-form documents.

The update is available on both web and mobile platforms, though the scope of features varies by platform. While support for viewing and editing PDF files is available on both web and mobile, editing capabilities for more complex formats like Google Docs, Sheets, presentations, and code files are currently limited to the web version. Google has rolled out these new capabilities to all users in all regions and languages supported by Gemini, with no additional subscription required. This move aims to integrate AI more deeply into daily office and software development workflows.
