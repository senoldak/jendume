Anthropic has introduced Claude Ship, a new suite of artificial intelligence agents that automates the final stages of the software development pipeline. While AI models have long been capable of writing code and performing initial checks, the final review and approval process has traditionally remained in human hands. Claude Ship introduces a novel capability by allowing organizations to delegate final approval authority to AI based on predefined organizational policies.

The new suite consists of three distinct parts: Code Review, PR Steward, and Claude Approvals. While Code Review is already generally available, PR Steward and Claude Approvals are currently in public beta. PR Steward handles issues such as merge conflicts and failing continuous integration checks, while Claude Approvals applies approval policies defined by the development team in a repository file. Together, these tools take GitHub pull requests from initial review through to final approval.

Anthropic recommends that early adopters run Claude Approvals in an observe-only mode and set monthly spending limits to maintain strict control. The feature is available for Claude Team and Enterprise subscribers with repositories hosted on GitHub. Internal metrics shared by the company indicate significant productivity gains, showing an increase in merged pull requests and a reduction in reverted code changes for engineering teams adopting the new workflow.
