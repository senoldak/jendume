NVIDIA has expanded its open-source Agent Toolkit with new tools designed to help enterprises customize, control, and govern autonomous AI agents using their internal data. Recognizing that agents are only as useful as their knowledge base and as trustworthy as their operational boundaries, the expanded toolkit provides a comprehensive stack for building production-ready agents. The updated offering includes the new NVIDIA Agent Knowledge Foundation with CUDA-X libraries, Nemotron Retriever and Kumo open models, OpenShell secure runtime, and NemoClaw blueprints. These components allow businesses to translate raw company data into familiar business concepts without moving data or altering existing governance workflows. Major enterprise partners, including Palantir, Databricks, Snowflake, Amazon Web Services, SAP, and ServiceNow, are already adopting the Agent Knowledge Foundation to power context-aware agents, improve search relevance, and optimize decision-making. By integrating these tools, enterprises can achieve faster search results, reduced latency, and enhanced document understanding across various operational workflows. The framework also includes the Auto-Ontology library which translates raw company data into business concepts such as customers, products, and orders, mapping how they relate. Kumo open models like Kumo Tabular, Kumo Relational, Kumo Time Series, and Kumo Forecast help agents find relevant information to answer questions and make accurate predictions.
