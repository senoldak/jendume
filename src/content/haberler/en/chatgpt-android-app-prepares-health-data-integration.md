OpenAI is developing a new health feature for the ChatGPT Android application. Discovered within the code of app version 1.2026.300, Health Connect integration will allow the chatbot to read activity data stored on mobile devices. This upcoming feature mirrors the Apple Health synchronization already available to iPhone users, addressing long-standing expectations among Android users following similar moves by competitors like Google Gemini.

Code analysis reveals detailed permission requests covering metrics such as weight, body fat, bone density, and menstrual cycles. These permissions are designed to make sense of the vast amount of data gathered by fitness wearables, transforming raw metrics into structured insights. Access to long-term historical records will further enable the AI to evaluate habits spanning several months.

Additionally, background synchronization permissions will allow the app to retrieve new fitness data even when closed, which OpenAI likely intends to use for personalized wellness recommendations and lifestyle guidance. At the same time, giving an AI assistant continuous access to sensitive body data brings forth valid privacy concerns that require transparent control mechanisms and strict safety boundaries.

Fitness and lifestyle suggestions must remain helpful without turning into unsafe medical advice, making rigorous standards essential for medical accuracy. Health Connect support currently resides in early test code and is not yet available to everyday users. OpenAI has not shared an official release schedule, and the final set of permissions remains undetermined while anticipation builds for future app updates.
