Exa Labs has released Exa 3.0, a major upgrade to its web search API designed specifically for AI agents. The new release introduces a larger embedding model, a cheaper search option called Exa Lite, and general availability for Dynamic Highlights. Exa operates its own crawler and an independent index rather than acting as a wrapper for traditional search engines.

The Exa 3.0 search API aims to improve information retrieval quality across various search types. The newly available Dynamic Highlights feature selects relevant tokens across all results instead of page by page, using significantly fewer tokens than full page text while maintaining answer quality. This addresses a major cost factor for AI agents where context tokens often surpass search call expenses.

Alongside the main release, Exa introduced Exa Lite to help reduce development costs. According to the platform changelog, Exa Lite runs on the same index as the Auto tier and costs four dollars per one thousand requests, offering a more budget-friendly alternative for developers.

Exa reported that Exa 3.0 Auto ranked ahead of competing solutions across eight benchmarks run by the company itself. These performance gains are attributed to three main changes in the retrieval stack, including the larger embedding model and billions of newly indexed documents covering e-commerce, local businesses, and research papers.

Despite the self-reported nature of the benchmarks, the expansion of searchable collections and optimized token usage represent notable technical steps forward for retrieval-augmented generation systems and autonomous agent workflows.
