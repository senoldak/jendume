Nvidia Corp. has expanded its networking infrastructure with the introduction of Scale-In, a purpose-built architecture designed to secure, manage, and operate agentic AI factories. As autonomous agents assume increasingly larger roles within enterprise systems, ensuring their containment and security has become a major priority. According to company executives, managing multiple agents running simultaneously requires robust infrastructure to ensure they remain within their designated sandboxes without compromising memory or storage.

Scale-In is powered by Nvidia's fourth-generation data processing unit, BlueField-4, alongside the DOCA software platform and Spectrum-X Ethernet technology. BlueField-4 acts as an out-of-band monitoring device equipped with in-silicon security engines that collect telemetry from memory, storage, GPUs, and CPUs. Meanwhile, the DOCA software framework enables developers to rapidly build cloud-native applications that offload and isolate data center workloads.

This announcement builds upon Nvidia's broader agent security strategy developed over recent months. In September, the company introduced the Open Agent Safety Platform, followed by the OpenShell Reference Architecture in October. Integrating Vera Rubin infrastructure, Vera CPUs, and Nvidia Sentry, these tools continuously monitor agent behavior and can automatically quarantine agents that attempt to breach their software boundaries.

These technological integrations highlight the shifting demands of modern data centers as they transition toward autonomous agent operations. By combining independent hardware enforcement layers with software runtime controls, Nvidia aims to provide a comprehensive framework for secure enterprise artificial intelligence deployment.
