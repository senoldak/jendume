Artificial intelligence models have enhanced software development and code migration capabilities in low-resource programming languages such as COBOL, Fortran, and Visual Basic. Unlike widely used languages like Python and JavaScript, these languages have less code and documentation available. However, they support critical infrastructure around the world, including over 40 percent of online banking systems, 80 percent of in-person credit card transactions, and 95 percent of ATM transactions.

Guided by developer feedback, new evaluations called MultiLangBench and COBOL migration tests measure model success in these areas. On MultiLangBench, GPT-6 Astra achieved an average test pass rate of 87.4 percent across 20 programming languages, compared to 26.8 percent for GPT-5.6 Sol. A lower-cost alternative, GPT-6 Luna, reached 40.3 percent while offering approximately 78 percent lower API costs.

In the COBOL migration evaluation, which tests moving code to languages like C++, Java, Kotlin, Python, or Rust, GPT-6.1 Sol achieved 86.6 percent accuracy at low reasoning effort. At higher reasoning effort, accuracy reached 97.9 percent, compared to just 5.4 percent for the previous GPT-5.6 Sol model at the same setting.

These results demonstrate that newer models can work across a broader range of programming languages at a lower cost. As organizations modernize their critical systems, these advanced capabilities enable them to update software without disrupting business processes.
