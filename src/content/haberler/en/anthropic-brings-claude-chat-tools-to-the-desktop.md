Anthropic has rolled out a new beta feature that lets users turn interactive tools created within Claude into standalone applications on Mac and Windows operating systems. The newly added installation option for Claude desktop versions assigns a dedicated window and icon to Artifacts generated during conversations.

Thanks to this update, users can directly access frequently used work tools without needing to search through past chat histories. Artifacts function as side-panel outputs such as lengthy texts, charts, or interactive interfaces. To install them on the desktop, users simply update their Mac or Windows Claude application, open the desired Artifact, and select the application installation option from the sharing menu.

According to Anthropic, the process does not require preparing separate packages, signing applications, or obtaining distinct API keys. These installed tools maintain access to Claude and its underlying connectors. For instance, the company highlights a meeting preparation page that regularly pulls data from calendars and emails as a primary use case.

Although the tool runs in its own window, it still requires an active internet connection and an open Claude session to function. Furthermore, Claude manages system permissions on a per-tool basis within desktop applications, limiting the default-permission tools to actions that can normally be performed inside a browser.
