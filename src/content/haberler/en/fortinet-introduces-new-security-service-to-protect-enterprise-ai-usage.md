Fortinet introduced the FortiGuard Inline AI Security Service solution to secure enterprise artificial intelligence usage. The company provides real-time artificial intelligence auditing and security protections through a cloud-based subscription model over existing FortiGate firewall infrastructure. This strategic move allows organizations to inspect prompts and model responses through the network devices they already use, eliminating the trouble of building a separate security stack.

Many artificial intelligence security products require separate and complex integrations for each application. Fortinet overcomes the bottlenecks created by these projects by utilizing widely installed FortiGate devices globally. Located at the center of network traffic, these devices can be made suitable for auditing with just a policy change without requiring a new security setup.

While first-generation security products focused only on discovering the use of tools, the new system analyzes the content of interactions in detail. Applying multi-layer protections on text, image, audio, video, and code contents, the system automatically identifies 35 different personal data types to prevent sensitive information from leaking outside the organization.

The solution also provides protection against financial attacks leading to uncontrolled token consumption. Administrators can audit spending from a central point by setting user or project-based budget limits. The company also offers an on-premises installation option and more than 50 predefined compliance policies for organizations with performance and data privacy requirements.
