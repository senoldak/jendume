OrcaRouter has officially released OrcaCyber Zero 1.5, a specialized model tailored for authorized security research, vulnerability reproduction, and penetration testing. Launched in October 2026, the model succeeds the previous version with advanced capabilities.

Equipped with a 1-million-token context window, the model can process massive codebases in a single pass. It aims to help security teams reason through complex attack paths, identify hidden flaws, and validate fixes more efficiently than before.

Available exclusively through an API for verified security professionals, the platform utilizes strict access tiers to ensure responsible use while offering high-performance threat analysis at competitive token pricing.
