Meta has announced Muse Spark Open, a new artificial intelligence model designed to run on Mac computers. The company has made the model available for developers who want to utilize and modify it for their specific requirements. Running this model on a Mac, however, demands a very high memory configuration. According to the setup detailed by the company, the system utilizes two Mac Studio computers equipped with M5 Ultra processors, each featuring 512 GB of memory, combining for a total of 1 TB of memory. This hardware setup relies on Apple's MLX software.

Such stringent hardware demands mean that the model cannot be operated on just any personal Mac computer. Meta built Muse Spark Open specifically for software development and multi-step computing tasks. The model is capable of analyzing text, image, audio, and video inputs to generate written responses, allowing developers to utilize it for coding assistance and debugging processes.

During internal testing, the company paired the model with a coding tool named Muse Code. According to Meta's disclosures, the model successfully fixed bugs and integrated new features into the Mastodon application Ice Cubes. In video editing tests using DaVinci Resolve, the model analyzed footage and cropped selected sections vertically. These specific examples are based entirely on the company's internal testing results.

Developers can access and download the model via the Hugging Face platform. Those who prefer not to run the software on their local hardware can alternatively access online services offering the model. Furthermore, Meta ties the usage and modification of the model to its specific license terms, which necessitate additional agreements for certain categories of commercial use.
