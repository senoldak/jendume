TypeSafe AI has released version 1.14 of Jev, its system decision model designed to return structured choices rather than open-ended text. The latest update introduces three experimental features under a preview alias, including image support, a new bounding box type, and an extended context window reaching 262k tokens.

The new image capabilities allow the model to handle visual inputs for tasks such as inspection and localization. However, the development team notes that these features are not yet fully ready for production environments and recommends starting with simple queries. Images are billed as standard input tokens without separate surcharges.

Another addition is the Box feature, which returns normalized bounding box coordinates for targeted objects within an image. Meanwhile, the long-context mode lifts previous limits to support up to 262k tokens per request, enabling the analysis of larger documents and data blocks while maintaining existing pricing structures.
