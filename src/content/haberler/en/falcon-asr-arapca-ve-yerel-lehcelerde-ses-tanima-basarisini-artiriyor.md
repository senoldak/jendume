The Technology Innovation Institute (TII) based in Abu Dhabi has introduced Falcon-ASR, a speech-to-text model designed to handle multiple languages with a single set of weights. Packing 1.6 billion parameters, the compact model supports Arabic, English, French, Spanish, and Portuguese without requiring language flags.

Focusing heavily on Arabic dialects and Emirati speech, the system achieved a 20.92% average word error rate across six Arabic test sets in internal evaluations, outperforming comparable models on specific benchmarks. It also captures word-level timestamps, making it useful for automated subtitling, meeting transcription, and searchable archives.

While the model demonstrates strong performance in handling background noise and varied speech patterns, access is currently limited to an online demonstration, with API integrations and native applications planned for the future.
