Anthropic is actively blocking its coding assistant Claude Code from recreating existing video games following a wave of unauthorized clones. Employee Addy Osmani confirmed that updated system instructions in the model now prevent the tool from cloning third-party games. Using AI models to infringe on intellectual property directly violates the company usage policy. The company has indicated that it plans to continue refining these rules to balance developer utility with intellectual property protection.

The update comes after a significant surge in AI-powered software cloning projects. Users had been leveraging advanced coding agents such as Opus 5.5 and GPT-6 Astra to rapidly generate unofficial browser ports of well-known video game titles. Coupled with reverse engineering tools, these AI agents made it easier to turn native binaries into readable code, expanding intellectual property battles from images and videos directly into software development. Tools combining AI agents with reverse engineering have also been used to recreate software and platform components, demonstrating how easily unauthorized replicas can be generated.

Despite the new restrictions, developers can still build their own original games and projects using custom assets. However, some users have reported occasionally running into limitations with entirely original workflows. These ongoing adjustments reflect the broader industry challenge of managing copyright compliance as generative coding technologies continue to advance rapidly across multiple development environments.
