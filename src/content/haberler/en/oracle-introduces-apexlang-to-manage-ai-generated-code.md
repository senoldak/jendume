Oracle has announced APEXlang, a new language designed to reshape application development in the artificial intelligence era. Mike Hichwa, senior vice president of software engineering at Oracle, noted that while humans wrote the majority of code in 2025, the majority will be machine-generated from 2026 onward. Vibe coding, the practice of instructing AI in natural language to write code, is rapidly turning from a novelty into daily practice, creating new governance challenges for organizations.

To tackle the management of machine-written software, Oracle developed APEXlang as a high-abstraction definition language that describes application goals rather than complex implementation steps. Announced alongside the APEX AI Application Generator, Oracle is releasing the language's grammar and documentation publicly. This allows coding assistants like Claude and Codex to generate the language. Furthermore, Oracle is working with partners to help models produce APEXlang more efficiently.

The design aims to reduce low-quality AI outputs by producing compact definitions instead of long, cluttered code. Hichwa compares the output to a lecture summary rather than a full book, making it much easier for humans to read and understand. When applications are generated numerous times within a company, portfolio consistency and governance become crucial factors.

Governance is also supported at runtime. The generated APEXlang is interpreted by the APEX engine, which Oracle refreshes every month with patches and updates. Consequently, customers do not need to constantly revisit the applications they have built, ensuring long-term maintainability without manual overhead.
