Mirendil has introduced Fern 0.1, its very first AI model aimed at research and development work rather than general chat. Fern 0.1 features an exceptionally large context window of up to 10 million tokens, which equals roughly 23 megabytes of code or about half a million lines. This allows developers to load an entire repository, a full training log, or days of agent traces simultaneously.

The model is targeted at specific use cases such as working across massive codebases, agentic coding that runs commands until tests pass, research code development, debugging long training logs, and auditing pretraining data. Built on Mirendil-Base, the foundational model was trained by a single researcher with the help of AI agents over a span of 3.5 months.

The total compute cost, including experiments and data processing, was kept under 10 million dollars, utilizing exclusively public data sources such as GitHub and web pages without any synthetic or licensed data. Fern 0.1 is the first of three planned models in Mirendil's pipeline.

While Fern 0.1 achieves strong results in long-context retrieval tasks like RULER, it still lags behind frontier models on certain agentic coding benchmarks. Nevertheless, its ability to maintain performance across extended context lengths marks a notable step forward in long-context AI modeling.
