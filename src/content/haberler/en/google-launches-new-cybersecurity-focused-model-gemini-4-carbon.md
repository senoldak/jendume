Google has announced Gemini 4 Carbon, a new artificial intelligence model designed for coding and autonomous tasks. Standing out as the company's most powerful model to date, Carbon was developed specifically for engineering tasks requiring long-term operation. According to internal tests, the model can identify and resolve complex bugs across large codebases and fix subtle errors in low-level systems.

Gemini 4 Carbon draws attention with its performance across various stages of cybersecurity. Achieving significant success in finding software vulnerabilities, validating exploits, and generating code patches that address root causes, the model claimed the top spot in the v5.0 release of the Artificial Analysis Intelligence Index with 59 points. It also achieved an 89 Elo point increase in the WebDev Arena rankings, reaching 1768 points.

The company states that it has more than doubled its secure code generation success rate compared to the previous model. Cloud security platform Wiz also highlighted Carbon's performance in web penetration testing. These capabilities are crucial for identifying vulnerabilities faster and making software more secure.

Google stated that it will roll out the model gradually due to security risks. Initially available to select cybersecurity experts, Gemini 4 Carbon's access will also be expanded to trusted partners under the Fairwind Program. The API pricing for the model is set at 2 dollars per million input tokens and 10 dollars per million output tokens, with a 95 percent discount on cached input tokens compared to standard input pricing.
