Greptile, a company that builds AI agents to review and test code changes with full codebase context, is advancing its testing capabilities through new AI models. According to Co-founder and CEO Daksh Gupta, the core mission is to reduce bugs and make global software more reliable. Achieving this goal requires testing application behavior rather than just reading code. While code review ensures logical correctness, certain visual or functional bugs—such as a button disappearing on a mobile viewport—only become apparent when the application runs. Using GPT-6 Astra, Greptile can start development servers, resize viewports, and simulate user navigation. The model's visual understanding allows it to inspect screens and catch hidden interface flaws that traditional quality assurance processes might miss. Gupta notes that manual testing firms cannot keep pace with modern software shipping speeds, making automated AI testing essential. In addition to functional testing, the company focuses on strengthening security defenses with Daybreak to ensure customers have sophisticated protection mechanisms against potential attackers. Greptile also connects Codex to its knowledge base through a Model Context Protocol server, allowing thousands of customers to write code that follows existing patterns and significantly reducing code reverts. Furthermore, Greptile is a massive user of Codex for building its own software and internal agents across engineering functions. Gupta explains that model intelligence is already sufficient for many tasks, positioning solutions like Ultrafast as key drivers to accelerate overall development and turn innovative ideas into working software efficiently.
