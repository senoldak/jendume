Perplexity launched its new autonomous agent system, "Teammates," for Max subscribers on the web on November 5, 2026. Unlike traditional chat-based AI models that wait for user prompts at every step, these agents operate proactively. They follow high-level goals in the background, utilize necessary tools, and can even message coworkers via Slack. This approach transforms AI from a simple question-and-answer tool into a virtual colleague that actively manages tasks.

The core vision behind this development is to shift the way users interact with AI from a "prompt-per-session" model to a "goal-oriented task assignment" model. When a user defines a task and a goal, the system leverages the Perplexity Computer infrastructure, utilizing projects, skills, and memory. Agents continuously monitor connected tools and take action when changes occur; however, they pause and seek user approval for critical decisions. Furthermore, agents can collaborate with one another to manage complex workflows.

Technically, each agent operates in its own isolated computer environment, with its own desktop and browser. This architecture provides a significant layer of security and privacy. Users can inspect the agent's desktop or take control if necessary. Passwords and account credentials are stored in an encrypted format, and agents are restricted from accessing these sensitive details directly. Plugins and skills are also limited to the permissions granted to the user.

Currently in research preview, this feature is available only to individual Max subscribers; Enterprise accounts are not included in this scope. The operation of these agents consumes the monthly credit allowance of the Max plan. Running multiple agents on complex tasks simultaneously can accelerate credit consumption. With this move, Perplexity advances its personal computer and browser strategy, aiming to make AI an active, collaborative partner in daily work.
