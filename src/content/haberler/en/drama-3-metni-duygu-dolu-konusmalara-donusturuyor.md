A notable advancement in generative audio has arrived with the release of a new text-to-speech model designed to interpret acting directions alongside written scripts. By placing bracketed cues before lines, writers can guide the emotional delivery and pacing of the generated voice, making automated speech much more expressive than previous iterations.

The architecture utilizes a mixture-of-experts approach, keeping active parameters low per token while maintaining high performance across multiple languages. Supporting dozens of languages and allowing multiple speakers within a single request, the system provides a comprehensive tool for scripted dialogue and immersive media creation.

While developers can self-host the model or access it via API, it requires dedicated graphics hardware to run efficiently. Released under a community license, it permits free commercial use for entities below a specific annual revenue threshold while explicitly prohibiting unauthorized voice cloning.
