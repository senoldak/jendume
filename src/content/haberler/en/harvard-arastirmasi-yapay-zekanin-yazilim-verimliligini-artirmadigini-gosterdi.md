A comprehensive research study on the impact of AI-driven coding assistants in software development has shown that increased code volume does not always translate into completed work. Covering the period from January 2021 to March 2026, the study examined approximately 300 million work events across 718 firms. The data was gathered using analytics tools and examined workers using generative AI technologies such as GitHub Copilot, Cursor, and Claude Code. The researchers evaluated output using metrics such as lines of code, commits, and pull requests. According to the findings, while AI assistants led to small increases in code output, and AI agents led to larger increases, these gains did not proportionally translate into a higher number of resolved issues and projects on tracking platforms. The researchers explained this gap by pointing to downstream bottlenecks in complementary steps such as code reviews and testing. Specifically, engineers were found to spend 30 to 40 percent of their time writing code, while the remainder goes to complementary tasks. As artificial intelligence raises productivity in code writing, these complementary steps serve as bottlenecks. The time required to review pull requests and the number of comments per review increased significantly, offsetting the initial speed gains provided by artificial intelligence and demonstrating the need to manage downstream tasks effectively.
