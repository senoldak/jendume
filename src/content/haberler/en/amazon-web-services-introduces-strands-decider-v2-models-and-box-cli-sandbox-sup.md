Amazon Web Services has announced a comprehensive expansion of its open-source framework designed for building autonomous software agents. The cloud platform released a new collection of open-weight decision models known as Strands Decider v2, alongside the introduction of Box CLI to deliver native sandbox isolation for popular coding agents.

Constructed upon Google's Gemma 4 architecture, the updated Strands Decider v2 models span multiple sizes, ranging from lightweight edge configurations up to a substantial 31 billion-parameter variant capable of handling intricate decision workflows. Internal evaluations conducted by engineers demonstrated that deploying these decision models successfully decreased labeling expenses by 98 percent while simultaneously accelerating ticket response times by 78 percent.

Complementing the decision models, the release features Box CLI as part of the Strands Box environment, functioning as an open-source operating system sandbox that enforces rigid security boundaries. By accommodating coding agents such as Claude Code, Codex, and Kiro CLI, the sandbox environment contains agent execution to prevent unintended file modifications or sensitive credential disclosures.

Published under an Apache 2.0 license across Hugging Face and AWS repositories, these newly introduced capabilities seek to maximize autonomous agent performance. Developers can now maintain continuous execution workflows while ensuring that critical security policies and access tokens remain safely isolated outside the active sandbox environment.
