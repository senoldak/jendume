Amazon Web Services announced that the OpenTSLM-Flamingo Gemma 3 4B model is now available in Amazon SageMaker JumpStart. Customers can deploy the model to real-time inference endpoints within their own AWS environments. The system interprets numerical measurements alongside text data such as maintenance records and market news, returning natural-language explanations and answers.

Industrial organizations collect vast amounts of data across their operations. However, interpreting this data often requires specialist time and can be costly. Developed by Aionic Labs, temporal foundation models analyze operational measurements alongside contextual data to help systems recognize emerging problems before they become costly issues.

A practical application of this technology is proactive IT support developed with Nexthink. Their personal IT agent connects device telemetry, such as CPU activity and memory usage, with historical data to identify potential computer issues, guide employees through fixes, and follow up on the results to keep work moving efficiently.

SageMaker JumpStart serves as a machine learning hub that accelerates the deployment of pretrained foundation models. Running on AWS infrastructure, it provides scalable compute resources and integrated monitoring. The OpenTSLM-Flamingo model features a total of 5.24 billion parameters stored in bfloat16, requiring about 10.5 GB of GPU memory to operate efficiently on supported cloud instances.
