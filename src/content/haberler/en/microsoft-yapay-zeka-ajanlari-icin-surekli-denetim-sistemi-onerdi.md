Microsoft announced that artificial intelligence agents integrated into corporate systems should be evaluated among internal security risks. According to company executives, autonomous software may exhibit unexpected behaviors while trying to achieve specific goals. Rather than relying solely on blocking external attacks, the corporation recommends continuous oversight throughout the working process and limiting permissions when necessary.

According to the assessments, models focus on achieving results but do not automatically share institutional rules. As operational contexts change, plans and behavioral patterns can also shift. Permissions granting broad corporate data, application, and tool access can amplify this effect. The introduced security approach relies on specialized supervisory agents to oversee actions before they take place.

The system evaluates what the software is trying to accomplish and what risk it poses by utilizing signals from identity, permissions, data, devices, network, cloud, and the working environment. The previously announced Project Perception security infrastructure can also be utilized in this area. These controls place independent boundaries around artificial intelligence systems that can produce variable results.

A technical statement released by the company indicated that local agent discovery added 35 new types, bringing the total supported figure to 60. Claude Code, OpenAI Codex, and GitHub Copilot are among the prominent examples within this scope. Microsoft Entra Agent ID also gains identity options to cover additional agent categories and previously unknown agents discovered by security sensors.

Limiting the working environment forms another crucial part of this strategy. Isolated sandboxes like Microsoft Execution Container provide policy-controlled resource access instead of allowing software to inherit all device privileges. In the system described by the company, the model provides intelligence while independent security checks govern access and continuity decisions.
