Design and collaboration platform Figma is expanding its connections to artificial intelligence tools while simultaneously addressing the boundaries of data sharing. Co-founder and CEO Dylan Field noted that the Model Context Protocol still requires refinement, even as the company announced twenty new partners during an event in India.

The newly added integrations include prominent platforms such as ClickUp, Linear, Notion, Mistral, and JetBrains. Field emphasized that users should be able to leverage their design data within their preferred workflows, while also carefully evaluating potential misuse risks as broader data access is established across various environments.

Model Context Protocol serves as an open standard enabling artificial intelligence applications to communicate with external data sources and tools securely. Instead of relying solely on static image previews, AI models can access structured design components, variables, and layouts to generate accurate outputs and code directly from the files.

Figma's official guidelines explain that this connectivity provides AI agents with the necessary context to generate code from design files. Supported tools can even write native content back to the canvas, although client capabilities depend on proper integration within the catalog.

Design context encompasses much more than a simple button appearance, involving components and layout details that affect how well generated results align with established design systems. While expanding ecosystem partnerships, leadership notes that permission scopes and data governance remain critical for secure workflows.
