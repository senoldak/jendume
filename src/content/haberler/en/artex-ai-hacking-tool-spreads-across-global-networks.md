Since late August, multiple companies, government agencies, and financial institutions worldwide have faced cyberattacks utilizing AI-powered penetration testing tools. These systems mimic legitimate defensive techniques by employing large language models to autonomously scan targets and execute attacks planned by human operators. Among these tools, the open-source framework Artex has gained significant traction within cybercriminal communities since its July release on GitHub. Written in the Go programming language, the software allows individuals with little technical expertise to launch cyberattacks at unprecedented speeds, reducing tasks that once took days down to mere hours.

The tool itself is not an AI product, but rather a guide that connects external frontier and open-source AI models to existing penetration testing tools. Users can issue simple natural-language prompts to initiate operations, after which multiple AI agents carry out the tasks. Researchers have linked Artex to various global campaigns targeting sectors such as finance, government, technology, energy, and health care. Incidents include the theft of personal information from South Korean financial institutions and hunting for exposed login details.

In October, groups such as Vapor Panda used Artex to target over 200 organizations, while Microsoft also spotted hackers using the framework to attempt system access. Although the original developer removed the tool from GitHub in October, multiple copies and alternative frameworks—such as CyberstrikeAI, Hexstrike, CAIRN, and PentAGI—continue to be utilized and developed. Security experts note that while these automated tools generate noticeable network activity and high volumes of requests, fundamental security measures remain crucial for detecting and defending against such intrusions.

Pinpointing the exact number of cybercriminals using Artex remains difficult, but researchers have found multiple exposed server instances left open to the internet. Basic security fundamentals, including patching software and monitoring unusual network activity, help defend against many of the approaches used by operators of these frameworks.
