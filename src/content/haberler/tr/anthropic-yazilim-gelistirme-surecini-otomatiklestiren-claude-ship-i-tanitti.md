Anthropic, yapay zekâ modeli Claude'un yazılım geliştirme sürecinin son aşamasını otomatikleştirmesini sağlayan yeni aracı Claude Ship'i kullanıma sundu. Şirket tarafından yapılan duyuruya göre bu yeni paket, kod inceleme, hata giderme ve onay süreçlerini üstlenen yapay zekâ ajanlarından oluşuyor. Geliştiriciler bugüne kadar yapay zekâ ile hızlı bir şekilde kod üretebildi, ancak son onay aşaması insan denetiminde kaldı. Claude Ship, kuruluşların önceden belirlediği politikalara göre kod değişikliklerini otomatik onaylayabiliyor.

Yeni paket üç ana bileşenden meydana geliyor. Bunlardan Code Review daha önceden genel kullanıma sunuldu, PR Steward ve Claude Approvals araçları ise şu an beta aşamasında yer alıyor. PR Steward, birleştirme çakışmalarını, başarısız test kontrollerini ve kod inceleme geri bildirimlerini yönetmek için tasarlandı. Claude Approvals ise ekiplerin kendi politika dosyalarına göre onay mekanizmasını çalıştırıyor. Geliştiriciler, GitHub depoları üzerinden bu ajanları etkinleştirerek süreçleri yönetebiliyor ve Claude Code aracı üzerinden /ship komutunu çalıştırabiliyor.

Anthropic, erken aşama kullanıcılarına Claude Approvals aracını ilk başta gözlem modunda çalıştırmalarını ve aylık harcama limitleri belirlemelerini tavsiye ediyor. Claude Team ve Enterprise abonelerine sunulan bu yeni araç seti, şirket içi verilere göre geliştirici ekiplerin birleştirilen kod miktarını artırırken geri alınan değişikliklerin oranını düşürdü. GitHub üzerindeki depolarla uyumlu olan paket, Code Review ve PR Steward için Anthropic bulut altyapısını kullanıyor.
